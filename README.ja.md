# FilmDevelop — 写真現像

印相／表示露出の標準範囲は ±8 EV、露出範囲拡張を有効にすると ±16 EV です。無効にしても既存の範囲外の値は保持します。

[繁體中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

![写真現像 — FilmDevelop](demo.gif)

Apple Silicon Mac 向けのフィルム風写真エディターです。写真フォルダを開き、フィルムを選び、現像・スキャン・階調を調整して書き出します。写真編集と AI 補助調整はローカルで実行されます。

macOS 14 以降に対応。AI 機能には、別途ダウンロードする互換ローカルモデルが必要です。

23 種類のコアフィルムに素材の初期設定を追加しました。「印相光源」の下に 4 種類のプリントレシピと、独立した銀濃度セクションを用意しています。「フィルムの初期設定」は元の印画紙設定を維持します。プリントした写真をスキャンする処理にも対応します。これらはソースに追加済みですが、下記の公開版にはまだ含まれません。

## 今回の更新 — 1.26.0925 build 1416

ニュートラル、暖色、ソフトポートレート、鮮やか、クリア寒色、褪色ヴィンテージの 6 種類を用意。商用スキャナーの実測プロファイルではありません。GR デジタルシミュレーションではスキャンを強制オフにし、設定全体を無効化。旧レシピや書き出しでも適用しません。フィルムとオリジナルでは使用できます。オリジナルの既定値ではニュートラルとオフは同じ外観です。

作業台の全 74 調整項目に説明があります。下線付きラベルをクリック、またはフォーカス後 Enter／Space で開き、Esc で閉じます。「機能説明を自動表示」がオフでもクリックで開けます。説明のクリックやダブルクリックは値を変更・リセットしません。オリジナルはフィルム一覧には表示せず、作業台に常時残し、初回起動時に選択します。

露出はフィルム色処理前の線形輝度に適用。通常 ±8 EV、拡張時 ±16 EV。ハイライト保護は有効時のみ働き、失われた元画像の細部は復元できません。Portra 800 の彩度順、Lomo Purple の赤保持、白平衡済み入力へのタングステン固定色偏移を調整しました。定性的な近似です。

`run.command` は不足する llama.cpp／libwebp サブモジュールを初回に取得します。ネット接続と完全版 Xcode が必要です。ビルド後は起動中のアプリを再起動して新しい画面を読み込んでください。

## ダウンロードと言語

[GitHub Releases](https://github.com/VaderChen/FilmDevelop/releases/latest) から Apple Silicon 用 DMG をダウンロードし、開いて `照片沖洗.app` を「アプリケーション」にドラッグしてください。正式インストーラーは Developer ID 署名と Apple の公証を完了しています。

繁体字中国語、英語、日本語、韓国語に対応。設定で選択するか、システム言語の自動検出を使用できます。ネイティブメニュー、ダイアログ、フィルム説明、ヒント、進行状況も切り替わります。ファイル名、カスタムフィルム名、ユーザーのプロンプトは変更しません。

## 主な機能

- **フィルムコレクション**：カラーネガ、映画用ネガ、リバーサル、モノクロ、インスタント、特殊プロセス。初期状態ではすべて選択され、ワークスペースに表示するものを変更できます。サイドバーの折りたたみ状態も保存します。
- **元の写真**：先頭の項目はフィルム効果を加えず、元の露出と階調から編集できます。
- **現像とスキャン**：粒子、現像、グロー、ハレーション、露出、コントラストを調整。ニュートラル、または暖かい中間調と涼しいハイライトのスキャンを選べます。
- **デジタル調整**：全体、ハイライト、中間調、シャドウを個別に調整。
- **切り抜きと回転**：元の比率、自由切り抜き、一般的な比率に対応。枠の角の外側をドラッグして回転。
- **取り消しとやり直し**：フォルダ選択の横にあるボタンで操作。連続したスライダードラッグは 1 ステップです。
- **写真ごとの保存**：フィルム選択、手動調整、AI 結果を写真ごとに保持。再度開いても AI は自動実行しません。
- **フレームと日付**：両調整モードでフレームやレトロカメラ風の日付を追加。

## 使い方

1. フォルダを選択してサムネイルから写真を開くか、写真をドラッグします。
2. 左側でフィルム、または元の写真を選択します。
3. 右側でフィルム／デジタルを選択。フィルムには現像・スキャン・フレーム、デジタルには全体・ハイライト・中間調・シャドウ・フレームがあります。
4. 必要に応じて AI 補助調整を実行するか、手動で調整します。
5. 書き出します。出力はサムネイルではなく元の写真から計算します。

### 閲覧とプレビュー

サムネイルは大・中・小の 3 サイズで、表示範囲だけ読み込みます。読み込み中はスピナーを表示。矢印は 1 枚分、ホイールは 3 枚分スクロールし、編集中の写真は切り替えません。前回のフォルダ、写真、スクロール位置を保存します。

写真上でホイールを回すと拡大縮小、左ボタンでドラッグすると移動します。最小倍率はウインドウに合わせます。スペースキーまたは比較ボタンを押している間、元の写真を表示。写真を 0.8 秒押すと左上に RGB ヒストグラムを表示し、× で閉じます。ヒストグラムは現在のプレビューに基づきます。

左側のフィルムにポインタを置くと、小さな画像で効果をプレビューできます。折りたたんだアイコンやカスタムフィルムにも対応。ポインタを外すか別ウインドウへ移ると元に戻り、編集履歴、赤いマーク、書き出しには影響しません。クリックすると正式に適用します。

### 切り抜き

オフ、元の比率、自由切り抜き、一般的な比率を選べます。元の比率は元画像の縦横比を固定し、固定比率は写真の縦横方向に合わせます。

枠内で移動、ハンドルでサイズ変更、角の外側で回転します。「完了」で適用。「キャンセル」またはオフでは今回の未確定変更を破棄し、以前に確定した切り抜きを保持します。

切り抜き中は通常編集と同じウインドウ合わせの高速プレビューを使用します。確定後は元画像から計算し、表示プレビューの長辺は最大 2048 px です。

### 修復ブラシ

切り抜きの左にある消しゴムアイコンを押し、上部ツールバーでブラシサイズを調整して不要な物体を塗ります。マウスを離すと自動で修復し、「完了」で現在のフィルム効果に戻ります。元ファイルを変更せず、写真ごとに保存され、取り消し・やり直しとプレビュー・フル解像度の書き出しに対応します。初期値に戻すと修復結果も直ちに除去されます。

消しゴムボタンを押すとモデルを確認し、準備完了後にブラシを有効にします。初回は約 217 MB の LaMa モデルをダウンロードします。進捗ダイアログに割合と転送量を表示し、キャンセルも可能です。準備完了後は Apple Silicon の Core ML を使ってオフラインで処理し、写真はアップロードしません。広い範囲の修復は不自然な細部がないか確認してください。

### 肌と描画の調整

レンズぼかしと美白の間に肌色の冷暖スライダーを追加しました。−100 は寒色、+100 は暖色、0 は中立で、肌マスク内だけに作用します。写真ごとの保存、取り消し・やり直し、初期化に対応します。美肌処理には輪郭を保つガイドフィルターを使用し、追加モデルは不要です。ノイズ除去はフィルム粒子より先に適用し、周辺光量補正は黒レベルを保ちます。

HDR は AI のトーンカーブがなくても調整できます。レンズぼかしの切り抜き・深度位置と被写体境界の色にじみを改善しました。スキャン・リバーサルでもプリント光源を変更でき、仕上がりに色補正を適用します。元の参照では従来の色を維持し、非スキャンのネガは分光プリント処理を維持します。書き出しボタンはアクセントカラーになりました。

### 調整と AI

フィルム強度の初期値は 50。元の写真を含むすべての内蔵フィルムでニュートラルスキャンが初期設定です。スキャン中も現像側で露出とコントラストを調整できます。露出は正で明るく、負で暗くなります。EVを上げるとハイライトを穏やかに圧縮し、下げると暗部の階調を保護します。0 EVでは元の見え方を保ちます。スキャン側は色の濃度、色層分離、迷光、中間調／ハイライトの色温度を調整します。

写真を開くだけでは AI は動作しません。互換ローカルモデルを選び、AI 補助調整を実行してください。中止でき、結果を手動で微調整できます。仕上がりは実際の写真で確認してください。

スライダーの調整領域をダブルクリックすると、その項目だけ現在のフィルムの初期値へ戻ります。取り消しも可能です。

初期値へのリセットは現在のフィルムの調整を戻し、取り消し／やり直し履歴とサムネイルの赤いマークを消去します。カスタムフィルムは保存した配合へ戻ります。新しい編集はやり直し履歴を消去します。履歴は現在の写真編集セッション内のみで、写真の切り替えや再起動後には残りませんが、写真の調整値は保存されます。

### 設定とプライバシー

機能説明は初期状態で有効です。見出しにポインタを置くと説明が表示されます。自動表示をオフにしても、見出しをクリックして読めます。元の解像度での編集は編集解像度を高め、オフでは操作が軽快になります。どちらも書き出しは元画像から行います。

写真、モデル、調整記録はローカルに保存します。モデル検索・ダウンロード・更新確認にはネット接続が必要ですが、ダウンロード済みモデルでの分析は写真をアップロードしません。上級者はローカル外部制御サービスを切り替えられます。接続設定にはアクセストークンが含まれるため、共有やコミットはしないでください。

### App の更新

「設定」と同じ行の右端にある更新確認ボタンから、GitHub の最新正式 Release を確認できます。ダウンロード中は進捗とサイズを表示し、キャンセルも可能。完了後にインストーラーを検証し、写真の調整を保存して更新・再起動します。

起動時もバックグラウンドで確認し、新版がある場合だけ通知します。オフラインや未公開時は編集を妨げません。更新には書き込み可能な「アプリケーション」フォルダへインストールしてください。版番号は台湾時間の `1.YY.MMdd build HHmm`（例：`1.26.0924 build 0109`）です。

更新元は [FilmDevelop Releases](https://github.com/VaderChen/FilmDevelop/releases)。公開リポジトリとインストーラー付き正式 Release が必要です。タグは `v1.YY.MMdd-build-HHmm`、ファイル名は `FilmYourPhoto-1.YY.MMdd-build-HHmm-arm64.dmg`。ローカル梱包ツールがビルドの版番号から生成します。

初期バージョンでダウンロード後に更新失敗のメッセージが出る場合は、[GitHub Releases](https://github.com/VaderChen/FilmDevelop/releases/latest) からインストーラーを入手し、旧アプリを終了して一度再インストールしてください。保存済みの写真の調整とカスタムフィルムは保持されます。新版ではアプリ名変更後の更新に対応し、失敗した場合は原因に応じた説明を表示します。

## ソースから起動

```sh
git clone --recurse-submodules https://github.com/VaderChen/FilmDevelop.git
cd FilmDevelop
./run.command
```

完全な Xcode が必要です。初回は依存項目をダウンロードする場合があります。Finder で `run.command` をダブルクリックすることもできます。App 内更新は自動再起動しますが、ソースを再ビルドした場合は旧 App を終了してから起動してください。

## 補足

フィルムやスキャナーの外観はシミュレーションであり、個別製品のメーカー実測値による再現ではありません。

テスト、研究文書（`doc/`、`docs/`）、ビルド・一時ファイルは開発者のローカルに保持し、公開リポジトリには含めません。必要なサブモジュールは記録され、`run.command` が呼び出すスクリプトが成果物を生成します。

写真の右クリックで、取り消し、やり直し、リセット、ヒストグラム、元の比率／自由切り抜き、書き出し、Finder 表示、ゴミ箱へ移動を利用できます。

PNG は初期設定で透明度なしの 8-bit RGB。透明な端はプレビューと同じ黒で埋めます。

書き出しアニメーションは現在の写真の処理済みプレビューキャッシュ（長辺最大 2048 px）を再利用し、ネイティブ処理の進捗に合わせて表示します。演出のために元画像を再処理したり、書き出した大きなファイルを再デコードしたりしません。書き出しファイルは引き続き元の解像度で計算します。

書き出し時は中央の大きなダイアログで、黒い背景から写真が徐々に現れます。写真サイズ、形式、過去の所要時間、実際の処理・保存進捗に合わせて進み、保存後に完成画像を表示します。高速な出力でも約 7 秒の現像演出を保ちますが、保存処理は演出を待ちません。

編集済みサムネイルには赤い点を表示し、リセットで消去します。元の写真でもスキャン、色の濃度、迷光、色温度を調整できます。プレビュー更新後、切り抜き右側のスポイトでグレーや白を選ぶとホワイトバランスを補正します。Esc で取り消します。

強度の上の保存アイコンで全調整をカスタムフィルムとして保存できます。カードの削除は配合だけを削除し、写真に適用済みの調整を保持します。再起動後も利用でき、後の写真編集で配合を上書きしません。切り替え時も内蔵フィルムの調整は保持します。ライブラリではカスタム／内蔵を区切り、ワークスペースでは元の写真、カスタム、内蔵の順。折りたたんだアイコンもクリックできます。

## 乳剤・現像・印画紙の設定

感色層の曲線と抑制、フィルム長辺（8–120 mm）、粒径分布、乳剤の解像感低下、仮想露光時間（0.0001–3600 秒）と相反則不軌、ハレーション吸収、追加銀濃度、現像温度（10–40°C）と活性、印画紙・散乱・紙白・最大濃度を調整できます。メーカーのフィルム・薬品・印画紙・スキャナーの実測値ではなく、芸術的な近似です。温度は相対反応モデルであり実際の処理条件ではありません。仮想露光時間は EXIF を読み書きしません。

旧レシピ用に残す 5 種を含む 23 種に控えめな素材設定を用意しました。保存済みレシピには新しい初期値を上書きしません。省略フィールドは従来値（長辺 36 mm、紙白 100、ハレーション吸収 50、20°C、活性 100）を使用します。CineStill 800T は吸収 35・ハレーション 28 で従来に近い赤の返照量を維持。Bleach Bypass の残留銀と、SX-70 の低い印相濃度は「フィルムの初期設定」で維持します。

### プリントレシピと写真スキャン

現像ページの「印相光源」の直下にプリントレシピを配置しました。既定値は「フィルムの初期設定」です。選択するとスキャン元をプリント写真に変更し、スキャンのオン／オフ・スタイル・露出・フィルム特性は維持します。リバーサル、オリジナル、デジタルカメラスタイルには適用しません。

| レシピ | 印画紙 | 散乱 | 紙白 | 黒濃度オフセット |
| --- | --- | ---: | ---: | ---: |
| フィルムの初期設定 | reference | 0 | 100 | 0 |
| 光沢プリント | glossy | 4 | 100 | 0 |
| マット・柔らかな階調 | matte | 22 | 96 | 0 |
| 温黒調ファイバー | warmFiber | 14 | 94 | 0 |

微調整でプリセットと異なる値にすると「カスタムプリント」と表示します。実際の値を写真やカスタムフィルムに保存し、取り消し／やり直しもできます。

スキャン元はフィルムの直接スキャン、または **フィルム → 光学プリント → 印画紙の効果 → 写真スキャン** を選択できます。写真スキャンでは紙白・濃度・散乱を残した後、スキャンスタイル・色・フレアを適用します。露出やネガの反転を重複適用せず、色層分離は無効です。スキャンをオフにするとプリントを出力します。直接スキャンとリバーサルには印画紙効果を適用しません。旧レシピは直接スキャンを維持します。写真スキャンは正像の芸術的モデルで、反射型スキャナーの実測再現ではありません。

### 銀濃度

独立した銀濃度セクションでは追加量 0 を「フィルムの初期設定」と表示します。0–100 のスライダーで中性の銀濃度を追加し、プリントと両スキャン経路に反映します。初期設定ボタンは追加分だけを戻し、Bleach Bypass を含む元の残留銀や、紙材・露出・スキャン設定は維持します。

MCP `update_adjustments` は `printRecipe`（`reference`／`glossy`／`matte`／`warmFiber`）、`scannerSource`（`film`／`paper`）、`silverRetention`（0–100）に対応します。同一バッチの個別指定はレシピ適用後に処理します。保存／AI JSON では `film_effects.scanner_source` と `silver_retention` を使い、プリントレシピは識別子ではなく紙材の実値で保存します。
