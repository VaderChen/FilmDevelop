# FilmDevelop

写真を好みのフィルムらしい仕上がりに。フィルムを選び、露出や色、粒子感を調整して書き出せます。

[繁體中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

![FilmDevelop](demo.gif)

## ダウンロード

[Mac 版をダウンロード](https://github.com/VaderChen/FilmDevelop/releases/latest)し、DMG を開いてアプリを「アプリケーション」へドラッグしてください。

**Apple Silicon・macOS 14 以降**に対応。繁体字中国語・英語・日本語・韓国語で使えます。インストーラーは Apple 公証済みです。

## 特長

- **フィルムから仕上がりまで楽しめる**：感色層、乳剤の粒子、現像液、印画紙、スキャンをシミュレーション。色調以外の質感も調整できます。
- **定番から自分だけの雰囲気へ**：Portra、Ektar、VISION3、Velvia、モノクロや特殊フィルム、GR III／GR IV のシミュレーションを選べます。好みの設定はカスタムフィルムとして保存できます。
- **写真ごとに編集を記憶**：調整、切り抜き、修復を写真ごとに保持します。元画像と比較でき、書き出しは元の写真から処理して、原本を上書きしません。
- **Mac 内で処理、AI は必要なときだけ**：写真と編集内容は Mac に保存。モデルをダウンロードすれば分析・修復もオフラインで使え、手動だけでの調整もできます。

## 機能一覧

| 機能 | できること |
| --- | --- |
| フィルムの管理 | お気に入り、並べ替え、強度調整。カスタムフィルムの名前変更、複製、読み込み、書き出し。 |
| 現像と質感 | 時間、温度、攪拌、コントラスト、粒子、グロー、ハレーションを調整。感色層、乳剤、相反則不軌、残留銀も試せます。 |
| スキャンと印画 | スキャナーのシミュレーション、フィルム／写真スキャン、光沢・マット・暖調ファイバー紙を選び、印画光源や色温度を調整。 |
| RAW・明暗・色 | オリジナルの露出とホワイトバランス、対応 RAW のレンズ補正。スポイト、明暗別露出、コントラスト、自然な彩度、彩度、HDR。 |
| 人物と細部 | 美肌、美白、肌の色温度、背景・レンズぼかし、ノイズ低減、周辺減光補正。 |
| ライブプレビュー | フィルムにマウスを重ねて試し、拡大、元画像との比較、RGB ヒストグラムで確認。 |
| 構図と修復 | 自由・固定比率の切り抜き、回転、AI 修復ブラシ、フレーム、日付。取り消し・やり直しにも対応。 |
| 写真の整理 | 複数選択、星評価、カテゴリ、並べ替え、絞り込み、EXIF 表示、最近のフォルダー。 |
| 複製と一括処理 | 調整付きで写真を複製し、調整を複数枚にコピー。一括でオリジナルに戻したり、書き出したりできます。 |
| 書き出し | JPEG・PNG・WebP・TIFF。PNG／TIFF の 8／16 bit、サイズ・品質、sRGB・Adobe RGB・Display P3 を選択。 |
| AI と外部ツール | 必要なときに AI 分析・調整を開始。ローカル MCP を有効にすると、対応する外部ツールから連携できます。 |

## まずは4ステップ

1. フォルダーを選び、写真を開きます。
2. 好きなフィルムを選ぶか、オリジナルから調整を始めます。
3. プレビューを見ながら調整します。取り消しや元画像との比較もできます。
4. 写真を書き出します。複数の写真も、それぞれの調整を保ってまとめて書き出せます。

写真や編集内容は Mac 内に保存します。AI モデルは初回にダウンロードが必要ですが、準備後はオフラインで使えます。

## 設定のヒント

**「システム標準の解析」と「システム標準の高速化」**を使用してください。内蔵ソフトウェア解析と Vulkan は Windows 対応の準備用テストモードです。Windows インストーラーはまだ提供していません。

フィルムやカメラの雰囲気はシミュレーションで、メーカー純正のプリセットや LUT ではありません。操作に迷ったら、アプリ内の機能名をクリックすると説明を読めます。
