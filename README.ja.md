# FilmDevelop

写真を好みのフィルムらしい仕上がりに。フィルムを選び、露出や色、粒子感を調整して書き出せます。

## ダウンロード

[Mac・Windows 版をダウンロード](https://github.com/VaderChen/FilmDevelop/releases/latest)。バージョンは **1.26.1002 build 1323**、Windows は **Beta** 表記です。

Mac は Apple Silicon・macOS 14 以降に対応。DMG から FilmDevelop を「アプリケーション」に移動します。今回の DMG と内包アプリは Developer ID 署名・Apple 公証・公証チケット添付済みです。Windows は 10／11 x64、WebView2 と VC++ x64 Runtime が必要です。x64 setup EXE を実行してください。Authenticode 署名はありません。

旧 Swift Mac 版は「アップデートを確認」から直接更新できます。FilmYourPhoto 移行パッケージは初回起動時に同じインストール先を標準 FilmDevelop 識別子へ移行します。追加ダウンロードは不要で、以後の更新は FilmDevelop を使用します。移行期間中は旧 Swift 版と従来の互換インストール向けの入口を維持します。認識できる編集、星評価、カテゴリ、カスタムフィルムを引き継ぎ、新版のデータを優先します。データベースの書き出し・読み込みと再配置で別の PC へ移せますが、元写真は含みません。繁体字中国語・英語・日本語・韓国語に対応します。

## 特長

- **フィルムから仕上がりまで楽しめる**：感色層、乳剤の粒子、現像液、印画紙、スキャンをシミュレーション。色調以外の質感も調整できます。
- **定番から自分だけの雰囲気へ**：Portra、Ektar、VISION3、Velvia、モノクロや特殊フィルム、GR III／GR IV のシミュレーションを選べます。好みの設定はカスタムフィルムとして保存できます。
- **写真ごとに編集を記憶**：調整、切り抜き、修復を写真ごとに保持します。元画像と比較でき、書き出しは元の写真から処理して、原本を上書きしません。
- **コンピューター内で処理、AI は必要なときだけ**：写真と編集内容は Mac に保存。モデルをダウンロードすれば分析・修復もオフラインで使え、手動だけでの調整もできます。

| 現像と質感 | 時間、温度、攪拌、コントラスト、粒子、グロー、ハレーションを調整。感色層、乳剤、相反則不軌、残留銀も試せます。 |
| スキャンと印画 | スキャナーのシミュレーション、フィルム／写真スキャン、光沢・マット・暖調ファイバー紙を選び、印画光源や色温度を調整。 |

## まずは4ステップ

1. フォルダーを選び、写真を開きます。
2. 好きなフィルムを選ぶか、オリジナルから調整を始めます。
3. プレビューを見ながら調整します。取り消しや元画像との比較もできます。
4. 写真を書き出します。複数の写真も、それぞれの調整を保ってまとめて書き出せます。

写真や編集内容は コンピューター内に保存します。AI モデルは初回にダウンロードが必要ですが、準備後はオフラインで使えます。

## 設定のヒント

RAW と演算の初期値は **システム** です。選択を保存し、起動時に利用可能な機能を再確認します。Mac は Apple の高速化を使用。Windows は実測確認済みの Vulkan GPU を優先し、利用できない場合は CPU へ切り替えます。RAW 解析には内蔵 LibRaw の代替経路があります。

17 社・31 機種の RAW 44 ファイルを検証し、LibRaw は 38 ファイルを解析、そのうち 37 が厳密なプラットフォーム間比較を通過しました。Nikon HE／HE* と GoPro GPR は未対応部分があります。ネイティブ RAW、被写体・深度、ノイズ低減、日付の字体には差が残ります。[検証記録](desktop/RESTORATION.md)をご覧ください。

フィルムやカメラの雰囲気はシミュレーションで、メーカー純正のプリセットや LUT ではありません。操作に迷ったら、アプリ内の機能名をクリックすると説明を読めます。
