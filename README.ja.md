# FilmDevelop

写真を好みのフィルムらしい仕上がりに。フィルムを選び、露出や色、粒子感を調整して書き出せます。

[繁體中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

![FilmDevelop](demo.gif)

## ダウンロード

[Mac 版をダウンロード](https://github.com/VaderChen/FilmDevelop/releases/latest)し、DMG を開いてアプリを「アプリケーション」へドラッグしてください。

**Apple Silicon・macOS 14 以降**に対応。繁体字中国語・英語・日本語・韓国語で使えます。インストーラーは Apple 公証済みです。

## できること

- **好みの雰囲気を選ぶ**：カラー、モノクロ、映画用フィルムや GR カメラのシミュレーションを選べます。自分の調整も保存できます。
- **仕上がりを調整する**：露出、ホワイトバランス、コントラスト、粒子感、現像、スキャンを細かく調整できます。
- **まとめて整理・編集する**：星評価やカテゴリで整理し、調整をコピーして複数の写真へ一括適用できます。
- **画面を整える**：切り抜き、回転、不要な物の修復に加え、フレームや日付も付けられます。
- **AI に手伝ってもらう**：モデルをダウンロードすると、Mac 上で写真を分析して調整を提案します。写真はアップロードしません。
- **作品を書き出す**：JPEG・PNG・WebP・TIFF に対応。サイズや色空間を選べ、元の写真は上書きしません。

## まずは4ステップ

1. フォルダーを選び、写真を開きます。
2. 好きなフィルムを選ぶか、オリジナルから調整を始めます。
3. プレビューを見ながら調整します。取り消しや元画像との比較もできます。
4. 写真を書き出します。複数の写真も、それぞれの調整を保ってまとめて書き出せます。

写真や編集内容は Mac 内に保存します。AI モデルは初回にダウンロードが必要ですが、準備後はオフラインで使えます。

## 設定のヒント

**「システム標準の解析」と「システム標準の高速化」**を使用してください。内蔵ソフトウェア解析と Vulkan は Windows 対応の準備用テストモードです。Windows インストーラーはまだ提供していません。

フィルムやカメラの雰囲気はシミュレーションで、メーカー純正のプリセットや LUT ではありません。操作に迷ったら、アプリ内の機能名をクリックすると説明を読めます。
