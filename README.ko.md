# FilmDevelop

사진에 좋아하는 필름 느낌을 더해 보세요. 필름을 고르고 노출, 색감, 입자를 조절한 뒤 내보내면 됩니다.

[繁體中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

![FilmDevelop](demo.gif)

## 다운로드

[Mac 버전 다운로드](https://github.com/VaderChen/FilmDevelop/releases/latest) 후 DMG를 열고 앱을 응용 프로그램 폴더로 드래그하세요.

**Apple Silicon Mac, macOS 14 이상**에서 사용할 수 있습니다. 번체 중국어, 영어, 일본어, 한국어를 지원하며 설치 파일은 Apple 공증을 받았습니다.

## 특징

- **필름부터 완성까지 직접 조절**: 감색층, 유제 입자, 현상액, 인화지, 스캔을 시뮬레이션해 색감뿐 아니라 질감도 다듬을 수 있습니다.
- **익숙한 필름에서 나만의 분위기로**: Portra, Ektar, VISION3, Velvia, 흑백·특수 필름과 GR III/GR IV 시뮬레이션을 고를 수 있습니다. 마음에 드는 설정은 사용자 필름으로 저장하세요.
- **사진마다 편집 내용 기억**: 조정, 자르기, 복구 내용을 사진별로 유지합니다. 원본과 비교할 수 있고, 내보내기는 원본에서 계산하되 원본 파일을 덮어쓰지 않습니다.
- **로컬 처리, AI는 필요할 때만**: 사진과 편집 내용은 Mac에 남습니다. 모델을 다운로드하면 분석과 복구도 오프라인으로 사용할 수 있으며 직접 조정만 해도 됩니다.

## 기능 한눈에 보기

| 기능 | 할 수 있는 일 |
| --- | --- |
| 필름 관리 | 즐겨찾기, 순서와 강도 조절. 사용자 필름의 이름 변경, 복제, 가져오기와 내보내기. |
| 현상과 질감 | 시간, 온도, 교반, 대비, 입자, 글로우, 할레이션 조절. 감색층, 유제, 상반칙 불궤와 잔류 은도 조절할 수 있습니다. |
| 스캔과 인화 | 스캐너 시뮬레이션, 필름·사진 스캔, 유광·무광·따뜻한 섬유 인화지를 선택하고 인화 광원과 색온도를 조절합니다. |
| RAW·밝기·색상 | 원본 노출과 화이트 밸런스, 지원 RAW의 렌즈 보정. 화이트 밸런스 스포이트, 영역별 노출, 대비, 생동감, 채도와 HDR. |
| 인물과 디테일 | 피부 보정, 미백, 피부 색온도, 배경·렌즈 흐림, 노이즈 감소와 비네팅 보정. |
| 실시간 미리보기 | 필름에 마우스를 올려 미리 보고, 확대·원본 비교·RGB 히스토그램으로 확인합니다. |
| 구도와 복구 | 자유·고정 비율 자르기, 회전, AI 복구 브러시, 테두리와 날짜. 실행 취소와 다시 실행도 지원합니다. |
| 사진 정리 | 여러 장 선택, 별점, 분류, 정렬·필터, EXIF 보기와 최근 폴더 열기. |
| 복사와 일괄 처리 | 조정을 유지한 사진 복제, 여러 사진에 조정값 복사, 원본으로 일괄 복원 및 내보내기. |
| 내보내기 | JPEG, PNG, WebP, TIFF. PNG/TIFF 8·16 bit, 크기·품질 및 sRGB·Adobe RGB·Display P3 선택. |
| AI와 외부 도구 | 원할 때 AI 분석·조정을 실행합니다. 로컬 MCP를 켜면 호환되는 외부 도구와 연결할 수 있습니다. |

## 네 단계로 시작하기

1. 폴더를 선택하고 사진을 엽니다.
2. 좋아하는 필름을 고르거나 원본에서 조정을 시작합니다.
3. 미리보기를 보며 조절하세요. 실행 취소와 원본 비교도 가능합니다.
4. 사진을 내보냅니다. 여러 장을 선택해도 각 사진의 조정을 유지한 채 함께 내보낼 수 있습니다.

사진과 편집 내용은 Mac에 저장됩니다. AI 모델은 처음에 다운로드가 필요하며 준비 후에는 오프라인으로 사용할 수 있습니다.

## 설정 팁

**시스템 기본 디코딩과 시스템 기본 가속**을 사용하세요. 내장 소프트웨어 디코딩과 Vulkan은 Windows 지원을 준비하는 테스트 모드입니다. Windows 설치 프로그램은 아직 제공하지 않습니다.

필름과 카메라 스타일은 시뮬레이션이며 제조사 기본 설정이나 LUT가 아닙니다. 사용법이 궁금하면 앱에서 기능 제목을 클릭해 설명을 확인하세요.
