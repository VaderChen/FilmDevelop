## 資料一致性修正

- 換照片、換目錄、原生開檔及關閉視窗前，提交尚在前端等待的滑桿與裁切；背景結果以照片世代及版本比對，不能覆蓋新選取。
- 關閉視窗的最後一批參數與關閉要求合併為同一筆指令，Go 先套用並保存再關閉，避免非同步事件讓關閉先於滑桿更新。
- 路徑與內容雜湊共同識別照片，同內容副本保持獨立；沿用舊 Go 及 Swift 紀錄時保留裁切、修復、自訂底片與手動調整標記。
- 修正「有已修過標記卻顯示原片」：Swift 的內容識別含 `sha256:` 前綴，Go 原先漏掉前綴而找不到配方。讀取來源標記可恢復先前被空白 Go 紀錄清除的狀態；僅回復無調整且歷史不完整的紀錄，保留 Go 後續編輯及明確重設。開圖後同步保存還原配方與標記，再產生預覽。
- 同一張照片的修復貼片只保存一份。修正先前在 37 款配方重複存放而超過容量的問題；契約單則訊息上限改為 64 MiB。
- 批次套用保留目標照片本身的修復，並同步手動調整標記；復原／重做保存整次交易。
- 修正 MCP 批次調整的 Go 型別轉接，工具要等預覽與 UI 確認完成才回覆。
- 初次前端載入只回報系統語言，不覆蓋已保存或遷移的語言偏好；系統選單沿用既有翻譯資料。
- 原生引擎缺失時，共用 Go 設定與配方仍可使用；不將缺少硬體模組當作整個宿主初始化失敗。

## 預覽顯影與下方進度

- 主預覽先取用列表的同一張縮圖；冷快取共用正在執行的縮圖工作，暖快取直接沿用，不重複解碼。初次顯影完成前，列表可視範圍變動不會清掉這張底圖。
- Swift 依目前配方處理影像；新結果解碼完成後，前端保留底圖，以 0→100% 不透明度逐步顯露套用參數後的照片。狀態更新不會中斷動畫，完成後釋放底圖；不同照片的過期結果不會插入目前畫面。
- 讀圖、更新預覽、主體偵測及顯示結果的等待文字與轉圈，統一放在照片顯示區下方狀態列。主體偵測提供下方取消按鈕，一般預覽不開浮動對話框、不鎖住編輯介面；完成後恢復一般預覽狀態。
- 減少動態效果設定會略過淡入動畫。直方圖、比較原圖、裁切、列表與匯出仍沿用原有操作。

## 切換計算加速的動畫對話框

## 連續參數預覽與加速設定

- 修正前端每 80 毫秒送值、Go 每次重設 120 毫秒等待造成拖曳期間完全不顯影的問題。Go 改成一份執行中工作與最新待處理參數，連續發布編輯縮圖；結束後短暫合併操作並補完整預覽。舊照片、底片與手勢的計時器及回覆均會失效。
- 拖曳過程不再逐筆寫入照片紀錄，也不重新投影全部 37 款底片。最後參數與結束操作依序入列，整次手勢只產生一筆復原紀錄；關閉、換圖與匯出仍保存最新參數。
- Swift 保留最近兩種尺寸的處理影像與原圖比較，消除切換編輯縮圖／清晰圖時重複縮放 RAW 的成本。Go 仍只負責 UI、配方、排程與持久化。
- 新資料預設為系統原生 RAW 解析與系統原生計算。已選後端不會被預設值覆蓋；相同選項仍可保存，設定寫入失敗會回復原選項。

| 指標 | 修正前 | 修正後 |
| --- | ---: | ---: |
| 開始拖曳至首張更新抵達 | 2.36 秒 | 0.48 秒 |
| 每次拖曳期間收到的更新 | 0 次 | 4 次 |
