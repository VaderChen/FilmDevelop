# 藥水參數與預設值

「藥水」指攝影沖洗用的化學試劑。介面用詞統一為英文 **Chemicals**、日文 **現像薬品**、韓文 **현상 약품**；相關說明以 processing chemicals／現像薬品／현상 약품 表達，避免使用容易被理解成醫藥品的泛稱。專指顯影液時使用 developer／現像液／현상액。

## 控制與範圍

| 控制 | 範圍 | 中性值 | 作用 |
|---|---|---|---|
| 顯影反差 | 0.60–1.50× | 1 | 調整 log-exposure／density 階調斜率 |
| 感度補償 | −1–+1 EV | 0 | 在曲線前位移曝光位置，每 EV 為 2 倍光量 |
| 高光補償 | 0–100 | 0 | 超過 0.36 線性亮度後逐漸壓縮亮部 |
| 顯影顆粒 | 0–100 | 0 | 加入共享於各色層的細微密度起伏 |
| 邊緣清晰度 | 0–100 | 0 | 在密度域強化鄰接邊界，限制過衝 |
| 紅／綠／藍色層反差 | 各 −20–+20 | 各 0 | 調整各色層隨曝光改變的相對響應；黑白停用 |

全部新控制均可獨立使用。原有顯影效果、時間、擴散、攪拌、溫度、活性繼續控制顯影液耗竭與補充，移到同一藥水頁。銀鹽密度與原本的曝光滑桿維持在沖洗頁。

## 計算順序與色彩

新階段位於白平衡、底片曝光、乳劑及原有顯影處理之後，片種曲線之前；數位調整、掃描與外框維持原次序。藥水設定隨風格強度混合，數位相機模擬不執行此階段。

1. 在 extended linear sRGB 中解除 alpha 預乘，以 D65 亮度計算 `x = log10(Y / 0.18) + EV × log10(2)`。
2. 設 `z = max(x − log10(2), 0)`，高光補償 `c = 值 / 50`。`c > 0` 時使用 `x' = x − z + ln(1 + c z) / c`，否則 `x' = x`。因此補償本身不改變暗部及中灰，曲線連續且單調。
3. 相對密度 `D = 0.08 + 2.4 / (1 + exp(−4 × 0.65 × contrast × x' / 2.4))`。參考反差為 1，Dmin 0.08、跨度 2.4；這些是曲線正規化係數，不是各片種的測量數據。
4. 選用邊緣清晰度時，以 Gaussian 鄰近密度求差 `d`，再使用 `d / (1 + |d| / 0.08)` 限制光暈；最大倍率 0.24。顯影顆粒採決定性密度雜訊，最大幅度 0.018；尺度以 3000 px 長邊為基準。
5. 使用參考反差的反函數還原正像亮度：`p = (D − 0.08) / 2.4`，`x0 = ln(p / (1 − p)) / (4 × 0.65 / 2.4)`，`Y' = 0.18 × 10^x0`。中性曲線的往返為恆等映射。感度 +1 EV 仍為 2 倍，沒有把 log10 與自然指數混用。
6. 僅明暗改變透過同一 D65 白點的 Lab 重建亮度並保留 a/b。色層反差則在 RGB 乘上 `10^(clamp(x', −3, 2) × channel / 100)`，再正規化回目標亮度；出界色彩沿中性軸收斂。黑白片忽略三色色層偏移。

極小補償值的 `ln(1+u)/u` 改用等價級數，避免 FP32 在 `1+u` 上遺失有效位數。若廣色域負色分量使色層加權亮度接近零或變負，先沿中性軸平移至目標亮度，再做出界收斂，避免用極小分母放大後互相抵消。

保留輸入 alpha 和 HDR 餘裕，黑色不平白抬灰；不在本階段逐色裁成 0–1。所有參數先檢查有限值與範圍，密度反函數限制奇點，極端亮度的相對倍率限制為 1/64–64。

## 效率

沿用現有 `PhotoGPUColorKernel` 的 Metal kernel 與 Core Image 執行環境，不新增 CPU 逐像素迴圈。明暗、Lab 色度重建、顆粒與色層反差共用一次回應 kernel；只有啟用邊緣清晰度時，才建立單一密度場與 Gaussian 鄰域。全中性、強度 0 完全略過。App 既有分階段 FP32 中間影像繼續控制記憶體與避免重算。

## 儲存與相容性

- 新選用或恢復底片預設：載入上表。
- 自訂配方、匯入配方：依 `baseStyle` 對缺少的 `filmEffects.developer_chemistry` 欄位逐一補值，明確保存的 0 或 1 也不覆蓋。
- 已存在的底片設定及照片編輯紀錄：由片種 ID 判斷預設，逐欄補齊缺少的新欄位，保存過的數值不改動；讀不到片種資訊時以中性補齊。
- 無底片基礎的原片、數位相機配方：缺少欄位仍為中性；數位相機成像不執行新階段。
- 預覽、匯出、MCP 更新與配方匯出共用同一設定；照片裁切與修復不加入配方。

## 研究依據

藥水的感度、反差、細粒與鄰接作用不能全由一個活性係數表示，因此分別提供控制。

- [Kodak D-76，J-78](https://business.kodakmoments.com/sites/prod/files/files/resources/j78.pdf)：時間、稀釋與反差的關係。
- [ILFORD 黑白藥水資料](https://www.ilfordphoto.com/amfile/file/download/file/1829/product/551/)：ID-11、PERCEPTOL、MICROPHEN 的細粒與感度取向。
- [Kodak XTOL，J-109](https://business.kodakmoments.com/sites/default/files/wysiwyg/pro/chemistry/J-109_Feb_2018.pdf)：感度、顆粒與銳利度。
- [ADOX RODINAL](https://www.adox.de/adox-chemie/adox-filmentwickler/rodinal-adonal/) 與 [FX-39](https://www.adox.de/adox-chemie/adox-filmentwickler/adox-fx-39/)：鄰接清晰度及補償型顯影。
- [Kodak ECN-2，Module 8](https://www.kodak.com/content/products-brochures/Film/Processing-KODAK-Motion-Picture-Films-Module-8.pdf)：製程條件對各感色層密度的不同影響。

文件支持參數分離與變化方向；上述起始係數是本程式的設定，未由同場景實拍配對擬合。既有保留銀處理維持獨立，不以中性密度曲線取代漂白旁路。

## 本次驗證

以 `test4.NEF` 的固定解碼影像（1200×800、FP32）比較全部 23 款底片，檢查中性與片種預設差異、黑白中性及有限數值；並逐款確認數位相機模擬輸出不變。新階段暖機後約 0.94–1.14 ms，為本機預覽尺寸測值，不含 RAW 解碼及完整底片流程。

另以灰階和彩色色塊檢查反函數、EV 倍率、極端值、高光單調性、Lab 色度、alpha、固定顆粒與邊緣界限；配方補值、匯入保存、MCP 橋接、AI grammar 與四語頁面均通過。測試程式及比較影像僅保留本機。
