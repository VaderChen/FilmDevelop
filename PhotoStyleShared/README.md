# PhotoStyleShared

Shared photo style plan and Core Image processing core used by the macOS app and CLI prototypes.

The package intentionally contains only app-safe code:

- `PhotoStylePlan`: structured JSON plan generated by an AI model.
- `PhotoPlanToneProcessor`: shared tone-zone semantics used by both the macOS app and CLI renderer.
- `PhotoStylizer`: standalone Core Image/Vision renderer used by CLI prototypes.

The macOS app composes the shared processors with its named-style signatures, interactive adjustments, decorations, and preview pipeline.

CLI-only process wrappers and llama.cpp command execution stay in `aiTest2`.
