# 極暗曝光補償（已停用）

自 **1.26.0927 build 1906** 起，極暗曝光補償已隱藏、不開放、不套用。介面移除控制，AI 產生格式及 MCP 不接受此參數；預覽與輸出均略過補償處理器。舊配方仍可讀取，但有效參數會歸零，不會恢復此效果。

以下保留停用前的演算法研究紀錄，**不代表本版可使用的功能**。原先 0～100% 代表原圖與局部補光結果的 RGB 融合比例，並非 EV。

## 採用的算法

2026-09-27 起採用確定性的 **線性 RGB 局部曝光增益**，不再執行 LYT-Net 的固定兩輪亮度增強，也不固定或手調 Lab a/b。舊模型、轉換工具和授權資源暫時保留，但不在曝光處理路徑使用。

1. 將輸入轉為 extended linear sRGB，以 D65 權重計算 `Y = 0.2126390059 R + 0.7151686788 G + 0.0721923154 B`，並取 `log2(max(Y, 1e-8))`。
2. 使用共用 `PhotoFastGuidedFilter` 建立保邊低頻基底 B。導引圖短邊上限256像素、正則化 `epsilon=0.04 stops²`；係數圖依原尺寸重建。導引資料允許負的 log 值，不套用 0～1 限制。
3. 基底曝光為 `EVlocal = clamp(0.55 × (log2(0.5) - B), 0, 6)`。這將暗部與亮部基準的 stop 差距縮短55%，保留約45%的基底階調斜率；極暗區最多增加6 stops。若直接把每個局部基底推至固定亮度，會出現大範圍階調平臺，因此不使用固定目標亮度方案。
4. 當原始 log Y 與基底的差距由0.1增至0.4 stops，以 smoothstep 改用相同公式的逐像素曝光，限制強邊緣附近的光暈。Y=0.12～0.8再平滑減弱曝光；Y≥0.8、Y≤1e-8與完全透明像素不變。
5. 在3×3小鄰域估計雙邊 RGB 均值與變異。取樣間距隨影像尺寸調整，1440長邊時為1像素，上限3像素；空間距離、log Y差距及RGB/Y色彩比例差距共同限制跨邊平均。
6. 局部不確定度為 `v / (v + 0.01 × meanY²)`，v為亮度權重加總的RGB變異。大增益與低亮度時，最多60%混合鄰域RGB；原始RGB仍至少保留40%。這只是保守的局部波動限制，**不是感測器噪聲估計或相機標定降噪**，也不能分辨所有細微紋理與噪聲。
7. 對上述RGB套用同一倍率 `2^EV`。確保正亮度不會因這個補光控制變暗；不逐通道截斷負色域分量、不截斷大於1的headroom。均勻色塊保留線性RGB色彩比例；噪聲區的鄰域混合允許有限的色彩修正。
8. 以 `RGBout = (1-p) × RGBin + p × RGBenhanced` 融合，p為百分比再乘strength。保留來源alpha。百分比與strength限制在有效範圍，非有限參數歸零。

0～100是補光結果的融合比例，因此50%不代表完整EV的一半。全域曝光仍應使用全域EV控制；純曝光+5的基準是RGB乘32，不是極暗補償100%。

## RAW與處理域

曝光前應使用已關閉預設shadowBias、boost及局部tone外觀的scene-linear RAW解碼。**FP32與extendedLinearSRGB本身不保證上游沒有烘入tone curve**。若輸入已壓低或截斷陰影，本控制無法恢復遺失的原訊號。

本處理器輸入是已去馬賽克的RGB，不是感測器Bayer資料。使用者照片與原始RAW不會被改寫。白平衡、相機色彩、底片效果及最後輸出映射仍分屬其他處理階段；此處不把SDR色域與高光映射混入曝光增益。

新舊底片曝光模式皆使用此控制，連動全區曝光不另外改動它，後續曝光歸零副本會清除它，以免套用兩次。配方鍵仍為 `deep_shadow_amount`，原生與Web bridge為 `deepShadowAmount`。

## 效能與驗證

Core Image／Metal負責導引與像素處理；提供renderContext時，只實體化小型導引係數圖，避免原生分塊匯出重複計算整段導引分支。沒有全尺寸CPU Lab緩衝區、Core ML模型載入或模型推論快取。

專用測試包含0%與舊配方相容、百分比／strength融合、6-stop範圍、無平臺且單調的階調、RGB色彩比例、負色域分量、飽和色、黑色／alpha／既有亮部保護、等亮度色邊、強邊緣光暈界限、合成色彩波動抑制、1像素與細長尺寸、平移與分塊、renderContext有無一致，以及新舊底片模式只套用一次。另確認改變輸入與百分比不會增加舊LYT模型的推論計數。

原生6048×4032的DSC_0899.NEF重新scene-linear解碼後，驗證各百分比輸出、原生全尺寸有限值、亮部保護與不變暗條件。研究PNG直接轉sRGB顯示，超過1的浮點headroom不會完整呈現；數值以RGBA FP32為準。真實圖、可重現測試、輸出與統計保存於本機研究目錄，不納入公開版本。

## 適用界限與後續工作

- 滑桿是局部陰影補光，亮燈本身不會像全域+5 EV一樣增加32倍。比較LR純曝光時應先比較相同RAW、白平衡與全域EV，再單獨比較局部補光。
- 同一曝光倍率也會放大噪聲；有限RGB鄰域平滑不能取代相機與增益適配的RAW降噪、聯合去馬賽克或條紋噪聲處理。極暗區仍可能有色斑與噪點。
- 導引濾波與局部曲線參數是有測試界限的工程選擇，不是感測器校準，也不宣稱實作完整Fast Local Laplacian或Lightroom內部演算法。
- 缺少同設定Lightroom原尺寸匯出及乾淨曝光真值，不能把提亮倍率、低變異或截圖相似度當作品質/SNR改善，也不宣稱已追上LR。
- 日後評估ELD／LED等RAW方法須取得正確的CFA與相機噪聲資料；不能把現在的RGBA buffer當成Bayer RAW輸入模型。保留此確定性基準，才可公平比較新方法。
